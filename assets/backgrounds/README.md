# Background Images

Drop the final WebP background image here.
Name it `map-bg.webp` (or update the CSS in `css/base.css` to match).

The image should be:
- Muted aerial street-drain/monsoon image.
- WebP format, optimized to ≤ 300KB.
- Ensure the image does not overpower the content (the CSS already adds a desaturating overlay).
